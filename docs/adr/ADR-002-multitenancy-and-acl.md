# ADR-002：租户隔离和 ACL 在检索前强制执行

## 状态

已接受；Phase 1 实现空间级 ACL，文档级 ACL 仍为端口预留能力。

## 决策

采用共享服务、共享基础设施、所有数据显式携带 `tenantId` 的模型。知识空间是
Phase 1 授权边界，支持用户、角色、部门和租户主体。查询运行时在调用每个
Retriever 前生成授权过滤器。`AccessScope` 保留文档白名单语义，但当前管理面
尚未提供文档级 ACL 生命周期。

## 原因

模型提示词和答案后处理不能阻止未授权内容进入模型上下文。过滤必须在所有召回通道中一致执行，并通过越权测试证明泄露率为零。

## 后果

所有 Store 和 Index SPI 都必须接收租户及访问范围；Neo4j 查询必须从带租户谓词的锚点开始；后台维护任务不得使用隐式超级管理员上下文。
