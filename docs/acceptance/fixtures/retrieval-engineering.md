# 工程检索故障手册

## 精确标识与接口名

检索错误码 `IKR-RET-042` 表示证据组装阶段无法找到活动修订。排查时先检查
`buildEvidenceBundle` 的输入是否仍指向当前活动修订，再核对投影任务是否完成。

## 缓存连接耗尽

当登录接口持续超时且缓存连接池已经耗尽时，先检查活跃连接数、等待队列、连接泄漏和
Redis 网络时延。确认连接能够按时归还后，再评估连接池上限；不要只通过扩大连接池掩盖泄漏。

## 认证链路的补充排查

如果初轮证据只说明缓存异常但不足以解释认证接口偶发抖动，应补充检索认证服务的调用超时、
Redis 连接获取等待时间、下游错误码和最近发布变更，并保留原查询中的接口名与错误码。
